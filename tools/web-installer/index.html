LilyGO T-2CAN · ESP32-S3

OpenHaldex installer

Flash the current build or select another compatible firmware without relying on a fixed serial-port name.

The helper built firmware and WebUI files from this checkout immediately before opening this page.

For OpenHaldex S3 build outputs. The correct board offsets are applied automatically.

Use only a complete ESP32-S3 flash image built for offset 0x0. An application-only firmware.bin is not a merged image.

Current local build is ready.

Use Chrome or Edge on a desktop computer to flash over USB. Serial access requires this page to be opened from localhost or HTTPS.

Leave Erase device off to preserve saved settings. The current local build always replaces the WebUI filesystem.

Connection help
  1. Connect the board with a data-capable USB cable and close serial monitors.
  2. If normal connection fails, hold BOOT, tap RESET, then release BOOT.
  3. Click Connect and choose the Espressif USB/JTAG serial device. Its port name may change; that is normal.
  4. After installation, press RESET once if the board does not restart automatically.

Only install firmware intended for the LilyGO T-2CAN ESP32-S3. Keep vehicle power disconnected while bench flashing.
